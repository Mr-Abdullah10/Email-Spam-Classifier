# 📧 AI Email Classifier

An end-to-end Machine Learning application that detects Spam emails using Natural Language Processing (NLP).

## 🚀 Features
- **Real-time Classification:** Instantly categorizes text as "Spam" or "Not Spam".
- **Confidence Scoring:** Uses Multinomial Naive Bayes algorithm.
- **Web Interface:** Built with Streamlit for easy user interaction.

## 🛠️ Tech Stack
- **Python** (Logic)
- **Scikit-learn** (Machine Learning)
- **Pandas** (Data Processing)
- **Streamlit** (Frontend UI)
